# ShopSphere – Modern E-Commerce Website

A responsive and interactive e-commerce website built using HTML, CSS and JavaScript.

## About the Project

ShopSphere is a modern online shopping demo that provides an attractive shopping experience with product browsing, wishlist management and cart functionality.

## Features

- Modern and responsive user interface
- Product search functionality
- Category-based product filtering
- Product sorting
- Product details popup
- Add to Cart functionality
- Buy Now option
- Wishlist management
- Quantity controls
- Automatic cart total calculation
- Local Storage support
- Demo checkout form
- Toast notifications

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Google Fonts
- Unsplash Images

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start exploring ShopSphere!
